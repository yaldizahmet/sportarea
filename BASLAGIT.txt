SporArea — kısa rehber
======================

Nerede ne çalışıyor?
--------------------
- Sunucu (API) + web sürümü : https://sportarea.onrender.com   (Render)
- Veritabanı                : Supabase, "yaldizahmet's Project" içinde "sportarea" şeması
- Saatlik zamanlayıcı       : Supabase pg_cron (haftalık maçı açar, maçtan 24 saat önce hatırlatır)

GitHub'da main dalına gönderilen her değişiklik Render'da otomatik yayına çıkar.
Uygulama (telefon ve web) her zaman canlı sunucuya bağlanır; bilgisayarda sunucu çalıştırmak gerekmez.


İLK KURULUM (bir kez)
---------------------
PowerShell'i aç, proje klasörüne git:

  cd C:\Users\user\Documents\sporarea
  npm run install:all

"npm" tanınmıyorsa: Node.js 20 veya 22 LTS kur (https://nodejs.org).


GITHUB'DAN YENİ KODU ALINCA (her seferinde)
-------------------------------------------
  git pull
  npm install --prefix mobile

Yeni paket eklendiyse ikinci komut şart; yoksa uygulama açılmaz.


UYGULAMAYI BİLGİSAYARDA DENEMEK
-------------------------------
Tarayıcıda (en kolayı):

  npm run mobile:web

  Açılan http://localhost:8081 adresinde giriş yap. Canlı sunucuya bağlanır.

Telefonda Expo Go ile:

  npm run mobile:tunnel

  Çıkan QR kodu Expo Go ile tara. Not: Push bildirimleri Expo Go'da çalışmaz, sadece APK'da.


1) WEB SÜRÜMÜNÜ GÜNCELLEMEK (ekranlarda değişiklik yaptıysan)
------------------------------------------------------------
Web sürümü server\public klasöründen sunuluyor. Ekran değiştiyse bunu yeniden üretmen gerekir,
yoksa sportarea.onrender.com eski haliyle kalır:

  npm run build:web
  git add -A
  git commit -m "Web sürümünü güncelle"
  git push

Birkaç dakika içinde Render yeni sürümü yayına alır.
Sadece sunucu kodunu (server\index.ts) değiştirdiysen build:web gerekmez, git push yeterli.


2) ANDROID APK ÇIKARMAK
-----------------------
  cd mobile
  npx eas build -p android --profile preview

İlk seferde Expo hesabınla giriş ister (npx eas login).
Derleme Expo'nun sunucusunda yapılır (10-20 dk). Sonunda çıkan indirme linkini gruba at.
APK uygulama kodunu kendi içinde taşır: ekranlarda değişiklik yaptığında Android'cilerin
yeni hali görmesi için yeni APK çıkarıp tekrar paylaşman gerekir.
Sadece sunucu değiştiyse (server klasörü) yeni APK gerekmez.


AYARLAR (Render > sportarea > Environment)
------------------------------------------
- JWT_SECRET    : uzun rastgele metin (değişirse herkes yeniden giriş yapar)
- DATABASE_URL  : Supabase "Session pooler" adresi, kullanıcı sportarea_app
                  postgresql://sportarea_app.nidydlccherwlhguylpj:SIFRE@aws-1-eu-west-1.pooler.supabase.com:5432/postgres

Veritabanı şeması: server\schema.sql


SORUN ÇIKARSA
-------------
- Uygulama "sunucuya ulaşılamadı" diyorsa: Render ücretsiz sunucu uykuda olabilir,
  ilk açılış 30-60 saniye sürebilir. Bekleyip tekrar dene.
- Render'da yükleme "Failed" ise: Render > Logs'taki son satırlara bak
  (çoğunlukla eksik JWT_SECRET / DATABASE_URL).
